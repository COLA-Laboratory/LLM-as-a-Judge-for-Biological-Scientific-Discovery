# Literature catalog

The 22 November 2026 register contains 251 domain studies, including six provisionally included from abstracts, and 32 general evaluation methods papers. Twenty-three reports await an eligibility decision. Where identifiable, versions of the same study share a register entry.

## Coverage by primary register category

Each domain study has one primary category in the register. A paper can illustrate several judgment tasks in the [research framework](../README.md#research-framework).

| Primary register category | Domain studies |
| --- | ---: |
| Workflow and output evaluation | 113 |
| Claim and evidence verification | 53 |
| Candidate prioritization | 52 |
| Review eligibility screening | 17 |
| Evidence and quality appraisal | 16 |
| **Total** | **251** |

This collection lists 40 domain studies and 28 general methods papers with links to their articles or preprints. The domain selections cover each of the five primary register categories. The source identifies the report or version used in the register.
